# 📋 Project 1: User Stories & Governance

## User Story 1: Developer Experience
**As a** Backend Developer,
**I want** to provision a standardized Node.js + PostgreSQL environment via Terraform,
**So that** I can deploy my code in under 5 minutes without manual AWS configuration.

## User Story 2: Compliance (DORA/GDPR)
**As a** Compliance Officer,
**I want** the database to be isolated in a private subnet,
**So that** we satisfy EU data residency and security audit requirements for 2026.

## User Story 3: FinOps (Cost Control)
**As a** Product Owner,
**I want** every resource to be automatically tagged with a CostCenter,
**So that** I can track the infrastructure budget for our B2B clients.
